## Description

**Portfolio de 3 pruebas técnicas React típicas** para nivel **Medior Frontend Developer**. Voy a ir subiendo algunas de las pruebas que he realizado para entrevistas en empresas de desarrollo de software.

**Objetivo:** Demostrar habilidades en:
- Manejo de estado con hooks (`useState`, `useEffect`, custom hooks)
- Consumo de APIs REST con manejo de loading/error
- Persistencia con localStorage
- Componentes reutilizables y responsive
- Buenas prácticas de código profesional

## Features

- ✨ **Counter** - Componente básico de estado
- ✅ **TodoList Avanzada** - CRUD completo + filtros + localStorage + custom hook
- 🎬 **Characters API** - Rick & Morty API + paginación + búsqueda + modal + responsive
- 🚀 **Navegación entre retos** con tabs interactivos
- 📱 **100% Responsive** - Funciona en móvil/tablet/desktop
- 🎨 **UI to improve UX** con hover effects y animaciones suaves

## Installation

### Prerequisites
- Node.js 18.0 or higher
- npm or yarn package manager
- Git (optional, needed to clone it)

### Setup Instructions
```bash
# Clona el repositorio
git clone https://github.com/tu-usuario/react-challenges.git
cd react-challenges

# Instala dependencias
npm install
# or
yarn install

# Inicia el servidor de desarrollo
npm run dev
# or
yarn dev
```

**Abre http://localhost:5173** 🎉

## Usage

**Navega entre los 3 retos usando los botones del menú superior:**

1. **📊 Contador** - Estado básico con React hooks
2. **✅ Lista Tareas** - CRUD + filtros + localStorage
3. **🎬 Personajes API** - API real + paginación + modal

**Cada reto es independiente** pero comparte el mismo diseño profesional.

## Contributing

¡Bienvenido! Este proyecto está abierto a mejoras:

1. **Fork** el repositorio
2. **Crea una branch** `git checkout -b feature/nuevo-reto`
3. **Añade commits claros** `git commit -m "feat: nuevo reto de formulario"`
4. **Push** `git push origin feature/nuevo-reto`
5. **Abre un Pull Request**

### Estructura recomendada para nuevos retos:
```
src/components/NuevoReto/
├── NuevoReto.jsx      # Componente principal
├── components/        # Subcomponentes
├── hooks/             # Custom hooks
└── services/          # API calls
```

### Code Style
```

✅ Custom hooks para lógica compleja
✅ Inline styles para prototipos (Tailwind/Stitches para prod)
✅ ESLint + Prettier configurados
```
